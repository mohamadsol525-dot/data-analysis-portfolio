# Data Analysis Portfolio

A collection of practical data analysis projects focused on **business insights, statistical analysis, exploratory data analysis, and data visualization**.

This portfolio demonstrates how raw data can be transformed into meaningful insights through structured analysis, visual exploration, and business-oriented storytelling.

---

## Projects

### Project 01 — Bike Rental Data Analysis

**Focus:** Customer Behavior, Demand Patterns & Urban Mobility

This project analyzes two years of bike-sharing data (2011–2012) using **JMP** to understand the behavioral differences between **Casual** and **Registered** users.

The analysis explores customer segmentation, annual growth, hourly and weekly demand patterns, seasonality, weather effects, and the response to extreme weather events.

**Key areas:**

- Customer segmentation
- Demand pattern analysis
- Time-based analysis
- Correlation and regression analysis
- Seasonal analysis
- Weather impact analysis
- Extreme event analysis
- Business insight generation

[View Project 01 →](./Project-01-Bike-Rental)

### Project 02 — Sales Performance & Business Insights

**Focus:** Sales Performance, Product Portfolio & Business Analysis

This project analyzes the sales performance of a food manufacturing company over the period **1399–1401**.

The analysis moves from overall sales performance to product groups, individual products, sales channels, sales representatives, and customers to identify the main drivers of growth, decline, and concentration risk.

**Key areas:**

- Sales performance analysis
- Year-over-year comparison
- Seasonal and monthly trend analysis
- Product portfolio analysis
- Sales channel analysis
- Customer analysis
- Sales representative analysis
- Sales concentration analysis
- Business insight generation

## Portfolio Approach

The projects follow a consistent analytical workflow:

**Business Question → Data Exploration → Pattern Identification → Statistical Analysis → Visualization → Business Insight**

The goal is not only to describe what happened in the data, but to identify **why patterns matter and what they may imply for business decisions**.
